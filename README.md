# 🧮 Python Calculator

A simple **command-line calculator** built with **Python 3**. It supports basic arithmetic operations, percentages, powers, and square roots.

## ✨ Features

- ➕ Addition
- ➖ Subtraction
- ✖️ Multiplication
- ➗ Division
- 📊 Percentage
- ** Power
- √ Square Root
- 🔄 Restart with `open`
- 🛑 Exit with `exit`

## 🛠️ Technologies

- Python 3
- `while` loops
- `if / elif / else`
- User input and arithmetic operators

## ▶️ Run

```bash
python calculator.py
```
